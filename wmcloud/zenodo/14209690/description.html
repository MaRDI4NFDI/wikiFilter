This dataset contains every distinct mathematical input of the English Wikipedia. enwiki_texvc_inputs.json maps the MD5 hash of each input to the input. This version has 676,297 inputs. The inputs of all Wikimedia projects are in 10.5281/zenodo.15162181.

The first version appeared as test/en-wiki-formulae.json in texvcjs.

Format

The input is the content of the tag as the Math extension receives it:

  • <chem> and <ce> tags are wrapped in \ce{…}.
  • The attribute display="block" wraps the input in {\displaystyle …}, display="inline" in {\textstyle …} and display="linebreak" in \[ … \].

Pipeline

  1. Keep the pages with math tags of the dump of 2026-09-01 (10.5281/zenodo.23098003).
  2. Import the filtered dump into a MediaWiki with the MathSearch extension.
  3. Store the input of every math tag of the current revisions in the table mathlog with the maintenance script UpdateMath.
  4. Export the inputs with exportDatasets.sh.

Every run is recorded in the log.

Changes

  • This version replaces en-wiki-formulae-good.json and normalized.json with the inputs of the dump of 2026-09-01.
  • Inputs longer than 65,535 bytes are complete.

Limitations

  • A math tag without a closing tag takes the rest of the page as its input, as in MediaWiki itself.
  • Formulae that come from templates, or that are written without tags, for example with the {{math}} template, are missing.
