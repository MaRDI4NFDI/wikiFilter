This dataset contains every page of all Wikimedia projects whose wikitext has a <math>, <chem> or <ce> tag. It covers the Wikipedias in all languages as well as Wiktionary, Wikibooks, Wikisource, Wikiversity, Wikidata, Commons and the other projects. It is the starting point for the other datasets on math in Wikimedia listed below.

Context

Mathematical formulae on Wikimedia wikis are written in a TeX dialect inside <math> tags and rendered by the Math extension of MediaWiki. To change the rendering, for example from images to MathML, all formulae in use have to be known and tested. This dataset makes them available without processing more than 400 GiB of dumps. It is maintained as part of the Mathematical Research Data Initiative (MaRDI). The refresh of this version is tracked in T439313.

Files

  • math.tar contains one file <dbname>.xml.bz per wiki with at least one tag, for example enwiki.xml.bz for the English Wikipedia. The files are bzip2-compressed MediaWiki XML exports with the current revision of each matching page, in all namespaces. They can be read with any XML parser or imported into MediaWiki with importDump.php. The database names are listed in the site matrix. This version has 663 files (1.6 GiB) from 1041 dumps.
  • inputHashes.csv lists every input dump with its path, size, creation date and SHA-256. 1028 dumps are from 2026-09-01; the others are the last dumps of closed wikis.

Pipeline

  1. Link the latest pages-articles-multistream dump of every wiki on Wikimedia Cloud VPS.
  2. Record the hashes of the dumps (inputHashes.csv).
  3. Keep the pages with math tags (math.tar, this dataset).
  4. Import each filtered dump into its own MediaWiki with the MathSearch extension.
  5. Export all formulae (10.5281/zenodo.15162181) and statistics per wiki (10.5281/zenodo.17838884).
  6. Render all formulae as MathML (10.5281/zenodo.15612155).

The steps are described in the README, and every run is recorded in the log. This version was made with updateLinks.sh, getInputHash.sh, filterMath.sh and wikiFilter.py.

Limitations

  • A page is only included if the tag is in its own wikitext. Formulae that come from templates, or that are written without tags, for example with the {{math}} template, are missing.
  • Private wikis have no public dumps and are not included.
