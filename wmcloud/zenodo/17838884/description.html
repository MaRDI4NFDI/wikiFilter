Statistics on the use of math in Wikimedia projects, based on the pages with math tags of the dumps of 2026-09-01 (10.5281/zenodo.23098003). This version covers 663 wikis, 590 of them with at least one math tag.

Columns of mathstat.csv

  • dbkey: database name of the wiki, see the site matrix for links to the current pages
  • no_formulae: number of math tags in the current revisions
  • no_pages: number of distinct pages that contain math

Pipeline

  1. Import each filtered dump into its own MediaWiki with the MathSearch extension.
  2. Index the math tags of the current revisions in the table mathindex of each wiki with the maintenance script UpdateMath.
  3. Count them per wiki with exportDatasets.sh.

Every run is recorded in the log. The inputs of all formulae are in 10.5281/zenodo.15162181.
