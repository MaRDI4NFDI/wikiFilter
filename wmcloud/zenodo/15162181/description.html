This dataset contains every distinct mathematical input of all Wikimedia projects, including the Wikipedias in all languages. wmf_texvc_inputs.json maps the MD5 hash of each input to the input. This version has 4,176,968 inputs.

Context

Mathematical formulae on Wikimedia wikis are written in a TeX dialect inside <math> tags and rendered by the Math extension of MediaWiki. To change the rendering, for example from images to MathML, all formulae in use have to be known and tested. It is maintained as part of the Mathematical Research Data Initiative (MaRDI). The refresh of this version is tracked in T439313.

Format

The Wikipedia article on mass–energy equivalence contains the wikitext

<math>E = mc^2</math>

Its input E = mc^2 has the MD5 hash 281a70c20b16a38d7781189936e1ac9f, so the file contains the row

"281a70c20b16a38d7781189936e1ac9f": "E = mc^2",

The input is the content of the tag as the Math extension receives it:

  • <chem> and <ce> tags are wrapped in \ce{…}.
  • The attribute display="block" wraps the input in {\displaystyle …}, display="inline" in {\textstyle …} and display="linebreak" in \[ … \].

Pipeline

  1. Keep the pages with math tags of the dumps of 2026-09-01 (10.5281/zenodo.23098003).
  2. Import each filtered dump into its own MediaWiki with the MathSearch extension.
  3. Store the input of every math tag of the current revisions in the table mathlog of each wiki with the maintenance script UpdateMath.
  4. Merge the inputs of all wikis and export them with exportDatasets.sh.

Every run is recorded in the log. The second import of all dumps duplicated 10 revisions in 3 wikis, because importDump compares the hash declared in the dump with a text that differs (T440235). The duplicates were deleted before the export, as recorded in the log.

Changes

  • Inputs longer than 65,535 bytes were cut off in earlier versions. They are complete now; the longest has 263,688 bytes.
  • Formulae that the page does not show, for example in parameters of missing templates, are included.
  • Math tags inside <nowiki>, <pre>, <source> and <syntaxhighlight> are not included.

Limitations

  • Most pages of Commons and some of Wikidata are missing, as the import stops at the content models wikibase-mediainfo and wikibase-item, which the wiki on math26 does not support.
  • A math tag without a closing tag takes the rest of the page as its input, as in MediaWiki itself.
  • Formulae that come from templates, or that are written without tags, for example with the {{math}} template, are missing.
  • Private wikis have no public dumps and are not included.
